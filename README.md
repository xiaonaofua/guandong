# 闯关东

清末“闯关东”背景的文字分支叙事小游戏：扮演一个山东黄县的普通人，靠一次次选择走完光绪二十五年（1899）到民国元年（1912）的十二年。

## 🌐 在线游玩

**https://xiaonaofua.github.io/guandong/**

## 🎮 玩法

- 点击 / 空格：让文字全部显示
- 数字键 1–4：做出选择（手机直接点）
- 进度自动保存在浏览器里
- 一局约二十分钟，共八个结局，可在“结局图鉴”里查看

## 📁 文件

- `index.html`：页面与样式
- `story.js`：全部剧情数据（改台词、加分支都在这里）
- `game.js`：游戏逻辑（打字机效果、数值、存档、结局图鉴）

## 🚀 本地运行

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

人物均为虚构，历史背景（庚子俄乱、夹皮沟韩边外、日俄战争、1910 年哈尔滨鼠疫等）尽量依据史实。
